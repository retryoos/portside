LaytimelyTechnology10

Built in-house

A frozen data contract, deterministic math, and prompt caching let us produce claims at cents each.

Stack

  • BackendFastAPI, async Python 3.12, Pydantic v2 frozen VoyageState contract, pdfplumber.
  • ModelClaude Sonnet 4.6 by default, Opus escape per agent. Prompt caching keeps cost at EUR 0.05–0.10 a voyage.13
  • FrontendNext.js 15, client-side PDF export, no native deps.
  • ScaleStateless agents, Postgres-ready, S3-ready, public API plus webhooks so TMS systems push docs in and pull packets out.

The trust architecture

The model classifies each event. A plain Python function walks the timeline, sums the hours, splits the row where the allowance runs out, and multiplies by the rate. The number on screen is reproducible and locked by a test to EUR 84,375.00.

That separation, LLM for judgment, Python for money, is why a shipping professional can defend our output in a dispute. No competitor that does the math inside the model can say the same.
